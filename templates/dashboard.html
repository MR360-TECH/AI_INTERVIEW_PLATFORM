Help & Frequently Asked Questions (FAQ)
Recruitment Assessment Mode

This is a formal, graded AI-driven assessment designed to evaluate your fitness for recruitment in a specific domain. The AI examiner adaptively prompts you with customized technical and fundamental questions.

  • Domain Customization: Select from diverse roles (e.g., Software Engineer, Data Scientist, HR Specialist).
  • AI Scoring: The AI scores each response dynamically on logical structure, technical depth, and professional terminology.
  • Placement Reports: Upon completion, a Placement Evaluation Report is automatically generated with detailed feedback for placement managers.
Practice Mode & Specialized Labs

A private, ungraded space to build confidence and hone your skills without scoring penalties.

  • Academic Viva: A comprehensive oral exam simulation tailored to test core academic and theoretical subjects.
  • FluentFlow: Multi-language conversational practice to master spoken English, French, Spanish, German, Japanese, Hindi, and more.
  • Debate AI: Engage in sharp, critical 2-line reasoning debates with the AI on user-defined topics.
  • Healthy Conversation: Talk about personal hobbies, general topics, or day-to-day concepts in a relaxed, friendly conversational mode.
Authentication & Profile Integrity

To ensure candidate integrity, secure sign-in is required via Google Sign-In or Email OTP. Recruiters rely on these verified details. You can update your skills, course, GitHub link, and LinkedIn profile link anytime in the Edit Profile section.

Assessment Results & Resets

Your certified evaluation history is permanently stored. You can view past details under "Assessment Performance History". If you need to restart a graded session, you can use the Reset & Start New Assessment button, which discards current progress to initiate a clean evaluation report.
